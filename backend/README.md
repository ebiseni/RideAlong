# RideAlong Backend

## Overview

This is the backend service for the RideAlong application.

It is responsible for:

- User Authentication
- Database Management
- API Development
- JWT Authentication
- Password Hashing

---

## Tech Stack

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT
- bcrypt
